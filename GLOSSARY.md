# Запись на звонок

Сервис позволяет пользователю забронировать временной слот для звонка.

## Термины

**Slot (Слот)**:
Временной интервал, предназначенный для бронирования звонка. Слот может быть свободным или занятым.
_Avoid_: Booking, запись — для обозначения самого временного интервала.

**Booking (Запись на звонок)**:
Результат записи пользователя на выбранный слот для звонка. «Бронь» — допустимая формулировка в интерфейсе.
_Avoid_: Slot, Event — для обозначения записи пользователя.
