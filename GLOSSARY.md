# Запись на звонок

Сервис позволяет пользователю забронировать временной слот для звонка.

## Термины

**Guest (Гость)**:
Человек, который без аккаунта и авторизации выбирает тип события и слот и создаёт бронирование, предоставляя обязательные имя и email.

**Owner (Владелец)**:
Единственный заранее заданный владелец календаря, для которого настроены типы событий, рабочее расписание и список предстоящих бронирований.

**Slot (Слот)**:
Временной интервал, предназначенный для бронирования звонка. Слот может быть свободным или занятым.
_Avoid_: Booking, запись — для обозначения самого временного интервала.

**Booking (Запись на звонок)**:
Результат записи пользователя на выбранный слот для звонка. «Бронь» — допустимая формулировка в интерфейсе.
_Avoid_: Slot, Event — для обозначения записи пользователя.

**Working Window (Рабочее окно)**:
Непрерывный интервал `[open, close)` внутри одного календарного дня в timezone календаря, в котором владелец доступен для бронирований. Задаётся для каждого дня недели; день без окна — нерабочий.
_Avoid_: рабочие часы — для обозначения самого интервала.

**Booking Window (Окно бронирования)**:
Период ближайших 14 календарных дат в timezone календаря (сегодня включён), в пределах которого гость выбирает слот.
_Avoid_: окно 14 дней — как неформальный синоним.

**Slot Grid (Сетка слотов)**:
Канонический набор допустимых стартов слотов выбранного типа события, построенный от начала рабочего окна с шагом, равным длительности типа.
_Avoid_: шаг слотов — для обозначения самой сетки.
